# Funngro Website Revamp — Evaluation Project

A two-page website redesign concept focused on the Teen and Company journeys.

## Pages

- Teen page: `/`
- Company page: `/companies/`

## Built with

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- Vite
- GitHub Pages deployment workflow

## SEO implemented

- Unique page titles and meta descriptions
- One clear H1 per page
- Semantic heading hierarchy
- Descriptive content built around user intent
- Responsive/mobile-first layout
- Final canonical URLs for GitHub Pages
- Open Graph metadata
- `robots.txt`
- `sitemap.xml`
- Accessible navigation and skip links
- Reduced-motion support

## Live URL after deployment

- Teen page: `https://debadityadutta.github.io/funngro-revamp/`
- Company page: `https://debadityadutta.github.io/funngro-revamp/companies/`

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages deployment

The repository includes `.github/workflows/deploy.yml`.

In GitHub, go to **Settings → Pages** and set **Source** to **GitHub Actions**. A push to the `main` branch will build and deploy the site automatically.

## Notes

This is an independent redesign concept created for an evaluation assignment. Brand statistics referenced in the concept were taken from Funngro's current public website at the time of the assignment.
